# Mental Youth Wellness Platform

A comprehensive mental wellness application designed to support youth mental health through interactive assessments, wellness exercises, and brain training activities.

## Features

- **MindCheck**: Mental health assessment quiz with personalized feedback
- **Wellness Studio**: Guided exercises and therapies for stress relief and wellness
- **BrainPlay**: Cognitive training games and activities
- **MindMate AI**: AI-powered mental health support assistant

## Tech Stack

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase (Backend & Authentication)

## Getting Started

### Prerequisites

- Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Installation

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd <YOUR_PROJECT_NAME>

# Step 3: Install dependencies
npm i

# Step 4: Start the development server
npm run dev
```

## Development

### Local Development

Run the development server with auto-reloading:

```sh
npm run dev
```

### Building for Production

```sh
npm run build
```

## Project Structure

- `/src/pages` - Main application pages
- `/src/components` - Reusable UI components
- `/src/assets` - Images and static assets
- `/src/integrations` - Backend integrations
